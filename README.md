Политех Расписание YPolytech.ru

Основная идея проекта - сделать просмотр расписания комфортным, быстрым и удобным.

Мы позаботились над ux/ui дизайном и постарались сделать использование нашего приложения максимально удобным на любом устройстве и в любом месте (оффлайн доступ к ранее загруженному расписанию).

Технологический стек

🚀 Frontend

Framework: React

Build Tool: Vite

Language: TypeScript

Styling: CSS

Routing: React Router

HttpClient: Axios

Persistence: IndexedDb with IDB library

📦 Development & Deployment

Version Control: Git with git-flow workflow

CI/CD: GitHub Actions

Containerization: Docker, Docker Compose

Hosting: VPS

🧪 Testing & Quality

Linting: ESLint, Prettier
